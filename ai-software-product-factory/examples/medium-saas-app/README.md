## What This Example Will Demonstrate

When fully built, this example will contain **filled-in versions** of all core documents plus relevant extension packs for a medium-complexity SaaS application. It shows how the factory handles multi-tenancy, subscription tiers, and more complex user interactions.

---

## Example Product Concept

A **Project Management SaaS** (or similar concept) with:

- **5-8 entities** (e.g., Tenants, Users, Projects, Tasks, Comments, Tags, Invitations, Activity Logs)
- **3-4 roles** (Super Admin, Tenant Admin, Member, Viewer)
- **Multi-tenant** data isolation
- **Subscription tiers** (Free, Pro, Enterprise)
- **Dashboard** with project metrics
- **Team management** (invitations, role assignment)
- **Notifications** (email + in-app)
- **Search and filtering** across projects and tasks
