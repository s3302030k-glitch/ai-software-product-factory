## What This Example Will Demonstrate

When fully built, this example will contain **filled-in versions** of all core documents for a small, straightforward CRUD application. It shows the factory at its simplest — proving that even small projects benefit from structured documentation.

---

## Example Product Concept

A simple **Task Manager** (or similar concept) with:

- **2-3 entities** (e.g., Users, Tasks, Categories)
- **2 roles** (Admin, User)
- **Basic CRUD flows** (Create, Read, Update, Delete for each entity)
- **Simple permissions** (Admin manages all, User manages own)
- **Single-tenant** (no multi-tenancy)
- **No complex business logic** (no calculations, no workflows)
