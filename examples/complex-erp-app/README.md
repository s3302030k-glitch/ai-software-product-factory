# Example: Complex ERP App

> Demonstrates how the AI Software Product Factory applies to a large-scale ERP system with multiple modules, workflows, financial logic, and reporting.

---

## What This Example Will Demonstrate

When fully built, this example will contain **filled-in versions** of all core documents plus multiple extension packs for a complex ERP application. It shows how the factory handles enterprise-grade complexity — multi-module systems, approval workflows, financial calculations, and operational reporting.

---

## Example Product Concept

A **Business Operations ERP** (or similar concept) with:

- **15+ entities** across multiple modules
- **5+ roles** with complex permission hierarchies
- **Multiple modules**: Inventory, Procurement, Sales, HR, Finance
- **Approval workflows** (purchase orders, leave requests, expense claims)
- **Financial calculations** (invoice totals, tax, discounts, P&L reporting)
- **Inventory management** (stock levels, transfers, reservations)
- **Operational dashboards** with KPIs per module
- **PDF report generation** (invoices, purchase orders, financial reports)
- **Audit trail** for all financial and approval transactions
- **Multi-currency support** (if international)
